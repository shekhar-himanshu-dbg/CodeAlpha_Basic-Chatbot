# 🤖 Basic Rule-Based Chatbot

A clean and professional Python-based rule chatbot developed for **CodeAlpha Task 4**.

The chatbot uses predefined rules to understand common user messages and provide appropriate responses.

---

## 📌 Project Overview

This project demonstrates fundamental Python programming concepts by creating an interactive command-line chatbot.

The chatbot can:

- Respond to greetings
- Respond to "How are you?"
- Handle thank-you messages
- Display the current date
- Display the current time
- Show a help menu
- Handle unknown messages
- End the conversation gracefully

---

## ✨ Features

- 🤖 Rule-based conversation
- 👋 Greeting detection

- 🕐 Current time command
