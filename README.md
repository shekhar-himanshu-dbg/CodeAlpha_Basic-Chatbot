# 🤖 Basic Rule-Based Chatbot

A clean and professional **rule-based chatbot** developed as part of **CodeAlpha Internship – Task 4** using Python.

The chatbot responds to common user messages such as greetings, questions about its status, date/time requests, help commands, and goodbye messages using predefined rules.

## 📌 Project Overview

This project demonstrates fundamental Python programming concepts by building an interactive rule-based chatbot.

The chatbot uses predefined responses and conditional logic to understand simple user inputs and provide appropriate replies.

### 💬 Supported Conversations

- 👋 Greetings
- 😊 "How are you?"
- 🙏 Thank-you messages
- 🕐 Current time
- 📅 Current date
- ❓ Help / commands
- 🤖 Unknown messages
- 👋 Goodbye / exit commands
